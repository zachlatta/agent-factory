Host load

The factory's host and every host in FACTORY_METRIC_HOSTS, read over SSH. In a VM, these are the VM's resources. CPU, load and RAM cover the whole machine, including work outside the factory.

Loading host metrics…

Refreshes every 2 seconds. Trends keep up to 5 minutes of samples while this page is open and reset on reload. Gaps indicate unavailable samples. Load counts running tasks and tasks waiting for disk; sustained load above the CPU count can indicate contention.

RAM used is total minus available, so reclaimable cache counts as available; on macOS, available is free, inactive and speculative pages, an estimate. Disk shows each host's home filesystem, not disk activity. Reserved disk space can make used plus available smaller than total.
