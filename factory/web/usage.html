How to read roles, stages and coverage
Fellow (fellow)
The card's agent owns planning, building, rework and landing.
Plan reviewer (plan reviewer) / code reviewer (code reviewer)
Separate agents check the plan or built work. A recorded review round is shown when available.
Scout (scout)
Looks for useful work and proposes ideas.
Repo picker (picker)
Chooses the repository for a request before its card starts.
Sub-agent (sub-agent)
A delegated Paseo agent belongs to its owning card, including nested delegation. Claude's built-in sub-agent files are included under their owning agent, card and stage, rather than shown as separate Paseo agents.
Other / unassigned
Other is the existing role for agents outside these factory roles. Shared sessions with conflicting owners or roles remain unassigned; duplicate references do not add tokens twice.
Recorded stages
Stages use the same identifiers and descriptions as the board. A span identifies a recorded visit, so repeated Building visits remain distinct; a round identifies a recorded review round.

Initial Codex cumulative readings, ambiguous intervals crossing stage boundaries, and missing or expired timing stay unassigned. Timing history is retained for 30 days. Stage attribution describes the recorded interval, not the current board column.

Scans are bounded to 2,000 metadata files, 32 MiB per session, 128 MiB of session data and 20 seconds. A limit or error can leave partial counts. Coverage includes built-in Claude sub-agent files. Missing, unsupported, duplicate and limit-skipped sessions are reported separately.

Records can disappear after cleanup and totals can shrink. Disappeared sources are detected against this process's prior inventory only on scans that are not limited; restarting forgets that inventory. Timing entries without agent metadata cannot supply token records.

Refreshes are cached for up to five minutes. This page polls for updated snapshots; reloading does not force a new collection. Transcript links are offered only for agents currently available through the board; older retained usage can outlive that access.
